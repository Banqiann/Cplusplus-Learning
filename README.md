# Cplusplus-Learning

我的 C++ 学习记录，按照「基础入门 → 核心编程」两阶段循序渐进，每个阶段配套对应的练习代码。

## 目录结构

```
Cplusplus-Learning/
├── 01-basic/      # 阶段一：C++ 基础入门
├── 02-core/       # 阶段二：C++ 核心编程
└── README.md
```

## 阶段一：C++ 基础入门（`01-basic`）

对应讲义 `C++基础入门.md`，主要掌握 C++ 基本语法与面向过程编程，内容如下：

| 章节 | 主要内容 |
| ---- | -------- |
| C++ 初识 | 第一个程序、注释、变量、常量、关键字、标识符命名规则 |
| 数据类型 | 整型、`sizeof`、浮点型、字符型、转义字符、字符串、布尔型、`cin` 输入 |
| 运算符 | 算术、赋值、比较、逻辑运算符 |
| 程序流程结构 | `if` / `switch` / 三目运算符、`while` / `do...while` / `for` / 嵌套循环、`break` / `continue` / `goto` |
| 数组 | 一维数组定义与数组名、冒泡排序、二维数组 |
| 函数 | 定义与调用、值传递、常见样式、声明、分文件编写 |
| 指针 | 指针定义与使用、空指针与野指针、`const` 修饰指针、指针与数组/函数 |
| 结构体 | 定义与使用、结构体数组/指针/嵌套、结构体做函数参数、`const` 使用场景 |

本目录下已包含基础练习代码，例如 `hello.cpp`、`交替合并字符串（双指针）.cpp`、`大数+1.cpp`、`异位词（sort）.cpp`、`棒球比赛.cpp`、`结构体（人物按年龄排序）.cpp` 等。

## 阶段二：C++ 核心编程（`02-core`）

对应讲义 `C++核心编程.md`，进入 C++ 面向对象编程的核心与精髓，内容如下：

| 章节 | 主要内容 |
| ---- | -------- |
| 内存分区模型 | 代码区/全局区/栈区/堆区、程序运行前后的变化、`new` 操作符 |
| 引用 | 基本使用、注意事项、引用做函数参数/返回值、引用本质、常量引用 |
| 函数提高 | 默认参数、占位参数、函数重载 |
| 类和对象 - 封装 | 类的定义与封装、访问权限、成员属性私有化 |
| 类和对象 - 初始化和清理 | 构造函数、析构函数、拷贝构造、深浅拷贝、初始化列表、类对象作为成员 |
| 类和对象 - 对象模型和 this 指针 | 成员变量/函数存储、this 指针、空指针访问成员、`const` 修饰成员函数 |
| 类和对象 - 友元 | 友元全局函数、友元类、友元成员函数 |
| 类和对象 - 运算符重载 | 加号、左移、递增、赋值、关系、函数调用运算符重载 |
| 类和对象 - 继承 | 继承基本语法、继承方式、对象模型、构造/析构顺序、同名成员处理、多继承、菱形继承 |
| 类和对象 - 多态 | 多态基本语法、纯虚函数与抽象类、虚析构与纯虚析构 |
| 文件操作 | 文本文件读写、二进制文件读写 |

## 如何运行

代码基于 Visual Studio 开发，也可用其他支持 C++ 的编译器（如 g++、Clang）编译运行：

```bash
g++ 01-basic/hello.cpp -o hello
./hello
```
