# Cplusplus-Learning

个人 C++ 学习记录，从基础语法练习到竞赛算法，循序渐进。

## 目录结构

```
Cplusplus-Learning/
├── 简单题/          # 基础语法与 LeetCode 题目
├── Luo_gu/          # 洛谷 NOIP 历年题解
├── 算法初探/         # 经典算法模板
├── .vscode/         # VS Code 编译调试配置
└── README.md
```

## 简单题

基础语法练习与 LeetCode 入门题，涵盖字符串操作、数组处理、结构体、指针传参等核心知识点。部分题目保留多个版本以便对比不同解法的思路差异。

## Luo_gu（洛谷）

NOIP 历年题目题解，涉及字符串匹配、排序去重、数论推导、结构体多关键字排序等。

## 算法初探

经典动态规划模板题，包括背包问题、最长上升子序列（LIS）、最长公共子序列（LCS）等。

## 开发环境

- 编辑器：VS Code / Trae SOLO CN
- 编译器：MinGW-w64 g++
- 调试：VS Code 集成 GDB
- 构建：`.vscode/tasks.json` 配置一键编译
